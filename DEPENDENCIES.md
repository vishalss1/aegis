# Dependency Inventory

This file records security-relevant dependency pins and integration constraints.
It complements the build files: a dependency is not considered active merely
because it is listed here.

## OpenSSL

Aegis uses OpenSSL EVP for X25519, ChaCha20-Poly1305, hashing, HKDF, secure
random generation, constant-time comparison, and secret cleansing. CMake
resolves the installed package with `find_package(OpenSSL REQUIRED)`.

## Wintun

The Wintun SDK is supplied out of tree through `WINTUN_DIR`. Its headers and
runtime DLL are intentionally not committed to this repository.

## Noise-C (selected, not active)

Handshake v2 will use a reviewed repository-local snapshot of the MIT-licensed
[Noise-C reference implementation](https://github.com/rweather/noise-c), pinned
to this exact upstream revision:

```text
commit: cfe25410979a87391bb9ac8d4d4bef64e9f268c6
date:   2023-12-07
```

Noise-C supports the required `Noise_IK_25519_ChaChaPoly_BLAKE2s` suite. Its
published documentation identifies Noise revision 30, while Aegis treats the
[Noise revision-34 specification](https://noiseprotocol.org/noise.html) as
normative. The dependency must therefore remain inactive until the selected IK
behavior passes official known-answer vectors and a source review of relevant
revision-31-through-34 changes.

Integration requirements:

- Vendor only the required sources, public headers, upstream license, and a
  retained-file manifest. Clean builds must not fetch code from the network.
- Hide all Noise-C pointers and error codes behind a narrow Aegis C++ wrapper.
- Install Aegis static keys explicitly and inject fixed ephemeral private keys
  generated by Aegis's checked `RandomSource`; do not use Noise-C's legacy
  Windows random path.
- Bind the canonical Aegis v2 prologue before the first message and permit no
  Noise handshake application payload.
- Copy authenticated keys, the final handshake hash, and split transport keys
  into cleansing Aegis storage, then immediately free dependency state.
- Collapse dependency and authentication errors into fail-closed local results;
  never expose fallback or handshake-v1 negotiation.

The active Session Manager continues to use the legacy handshake until the
vendored wrapper, official vector, deterministic round trip, and negative tests
all pass the warning-as-error build and full CTest suite.
